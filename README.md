# TimelapseChecker

SharpCap Pro 等で撮影している太陽タイムラプスの出力フォルダを監視し、画像の変化から異常の兆候（雲・ルーフによる遮蔽、追尾エラーによる見切れ）を検出して、画面表示と警告音で知らせる Windows デスクトップアプリです（WPF, .NET 8）。

## 検出できる事象

| 事象 | 反応する指標 |
|---|---|
| ルーフで太陽が徐々に隠れる | 円盤の面積比の低下（初期は「面積が連続して減少中」で注意） |
| 雲の通過 | 面積比・コントラスト比の低下、背景の持ち上がり、明暗差の低下 |
| 追尾エラー（画角ずれ・見切れ） | 重心ずれ（円盤半径比）、画像端への接触 |
| 画像処理で太陽が画角から外れた | 端の引き伸ばしノイズ（端の行・列が複製されて縞状になる現象）の強さ |

## 相対値による判定

撮影ごとに輝度・色味が変わっても動作するよう、絶対値は一切使いません。

- 円盤の切り出し閾値は、その画像自身の「背景(下位5%)〜明部(上位0.5%)」の中間
- 判定は「直近10枚の正常フレームの中央値」および「基準画像」に対する比
- 位置ずれは、基準円盤の半径に対する比

異常と判定されたフレームは基準に取り込まないため、遮蔽が進行しても基準は追従しません。意図的に太陽を再導入した場合などは「最新画像を基準にする」または「指定...」で基準画像を設定し直してください。

## 指標の推移グラフ

画面右側に、監視中の指標の推移を**直近30分固定**でリアルタイム表示します。

| グラフ | 内容 |
|---|---|
| 上段 | 面積比（基準に対する円盤の面積） |
| 下段 | 重心ずれ（円盤半径に対する比） |

- 黄色の破線が「注意」、赤色の点線が「警告」の閾値です（「判定設定」の値が反映されます）
- 横軸は現在時刻までの30分幅で、罫線は5分刻みです
- 新しい画像が届くたびに点が追加され、画像が届かない間も10秒ごとに横軸が進みます
- 監視を開始するたびにクリアされます（過去のログの読み込みやレンジ変更はできません）

## 使い方

1. アプリを起動し、監視フォルダにSharpCapのタイムラプス出力フォルダを指定して「監視開始」（フォルダは保存され、次回起動時に復元されます）
2. 監視開始時点でフォルダ内にある画像の先頭の1枚（ファイル名順）が基準画像になります。端のノイズがある画像は基準にせず、次の画像を使います。以降に出力された画像が順に判定されます（起動時点で存在する他のファイルは判定対象外）
3. 基準画像は画面上部に表示され、「指定...」で任意の画像に、「最新画像を基準にする」で直近の画像に切り替えられます。基準が変わるとプレビューに反映されます
4. 「警告」になると、ウィンドウが前面に出て警告音が一定間隔で鳴ります。「確認」で音を止められます。確認後でも、新しい画像で問題が判定されると警告音が再開します
5. 閾値・警告音(wav/mp3)・自動開始は「判定設定」で変更でき、`settings/` に保存されます
6. フレームごとの指標は `settings/log/yyyyMMdd.csv` に記録されます（閾値調整用。端のノイズ強度の列を含みます）

## 構成

```
TimelapseChecker.Core/     画像解析と判定ロジック（UI非依存, OpenCvSharp）
TimelapseChecker.App/      WPFアプリ本体（CommunityToolkit.Mvvm, グラフ: LiveChartsCore.SkiaSharpView.WPF）
TimelapseChecker.Replay/   既存フォルダを順に判定して結果を表示する検証用コンソール
```

検証用ツールの実行例:

```
dotnet run --project TimelapseChecker.Replay -c Release -- success_case fail_case
```

## ビルド

```
dotnet build TimelapseChecker.slnx -c Release
```

配布用のシングル exe:

```
dotnet publish TimelapseChecker.App -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=none -p:DebugSymbols=false -o publish
```

## 動作環境

- Windows 10 Build 19041 以降
- .NET 8
